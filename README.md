# IE7615 Discriminative Project – Milestone 2: Multi-Object Detection with YOLOv8

Object detection on multi-object images built from the single-object photos of the course dataset (IE7615 Deep Learning for AI, Fall 2026). We combine single-object photos into grid images, custom-train **YOLOv8s** on them, and use the trained model to report the **Object ID and location** of every object in a new multi-object image.

The work uses the **38 Section 1 objects** (Object IDs from the shared sheet) and **3,605 photos** at 224×224 from the Milestone 1 dataset.

## Repository contents

| Path | Description |
| --- | --- |
| `notebooks/Milestone_2.ipynb` | The full pipeline. **Task 1**: automatic bounding boxes with YOLO-World and Grounding DINO, box fusion with a 20% per-object drop limit, visual checks, and generation of the multi-object grid dataset with YOLO labels. **Task 2**: YOLOv8s training (with a resume cell for Colab disconnects) and test evaluation. **Task 3**: per-object evaluation, example detections, a post-processing comparison and the final `detect_objects` function |
| `requirements.txt` | Python packages used |

## Dataset

The photos come from the course's Final Merged Dataset and are **not included** in this repository. The notebook reads `dataset_224.zip` and `metadata.csv`, which are produced by the Milestone 1 preprocessing notebook ([Milestone 1 repository](https://github.com/RajivPraveen/IE7615-Discriminative-Project-Milestone1)).

- The Milestone 1 train/validation/test split is reused (2,509 / 533 / 563 photos), so a source photo can never appear in more than one split.
- Photo `OBJ054_017` is excluded because it does not show the object.
- The dataset has object IDs but no bounding boxes. Boxes were generated by two open-vocabulary detectors (YOLO-World `yolov8l-worldv2` and Grounding DINO `grounding-dino-base`) and fused. 3,048 photos were kept, and no object lost more than 20% of its photos.
- Grid images are built from 2×2 up to 5×5 photos (448×448 to 1120×1120 pixels), with a random horizontal flip and brightness change for each photo: **400 train, 80 validation and 80 test grids**.

## How to run

The notebook was written for **Google Colab with a GPU runtime** (Runtime → Change runtime type → T4 GPU).

1. Run the Milestone 1 preprocessing notebook first, or copy its `dataset_224.zip` and `metadata.csv` into a Drive folder.
2. Open `notebooks/Milestone_2.ipynb` in Colab and set the paths in Task 1, Step 1:
   - `M1_DIR`: the folder with the Milestone 1 output (default `/content/drive/MyDrive/IE7615_pytorch`)
   - `M2_DIR`: where this milestone's labels, logs and checkpoints are saved (default `/content/drive/MyDrive/IE7615_detection`)
3. Run **Task 1** (Steps 1–9). This writes `labels.csv`, `dropped_photos.csv`, `per_object_summary.csv` and `grid_log_main.csv` to `M2_DIR`, and the grid images with their YOLO labels and `data.yaml` to `/content/grids`.
4. Run **Task 2**. Step 2 trains YOLOv8s and saves it to `M2_DIR/runs/yolov8s_main_seed42`. If Colab disconnects, regenerate the grids (Task 1, Steps 1 and 8) and run the resume cell (Step 3). Step 4 evaluates `best.pt` on the test grids.
5. Run **Task 3** for the per-object results, example detections, the post-processing comparison and the final detection function. The results are saved to `M2_DIR/evaluation`.

Using the final detector on any grid image:

```python
found = detect_objects("path/to/grid.jpg", show=True)
# [{'object_id': 'OBJ064', 'name': 'RGB Projector', 'confidence': 0.788,
#   'box': [78.5, 79.1, 137.5, 119.3], 'row': 0, 'col': 0}, ...]
```

To install the dependencies locally:

```bash
pip install -r requirements.txt
```

## Model and training

| Setting | Value |
| --- | --- |
| Model | YOLOv8s, COCO-pretrained, detection head replaced for 38 classes (11.15M parameters) |
| Image size | 1120 (the size of the largest grid) |
| Epochs / batch | 80 / 8 |
| Optimizer | AdamW (lr 0.000238, chosen automatically by Ultralytics), mixed precision |
| Augmentation | Mosaic off (the grids are already multi-object images); Ultralytics defaults for HSV, flip, translate and scale |
| Seed | 42 |
| Hardware | Tesla T4, 0.52 hours |

## Results

| Evaluation | Objects | Precision | Recall | mAP@0.5 | mAP@0.5:0.95 |
| --- | --- | --- | --- | --- | --- |
| Validation grids (best epoch 57) | 1,237 | 0.950 | 0.926 | 0.955 | 0.902 |
| Test grids (Task 2) | 1,166 | 0.922 | 0.917 | 0.928 | 0.880 |
| Regenerated test grids (Task 3) | 1,316 | 0.925 | 0.896 | 0.922 | 0.871 |

- 20 of the 38 objects reach AP@0.5 ≥ 0.95. The weakest are the Mouth guard case (OBJ042, 0.474), the Wireless powerbank (OBJ048, 0.711) and the NoteBook (OBJ003, 0.733).
- Keeping only the most confident detection in each grid cell raises precision from 0.921 to **0.947** and F1 from 0.916 to **0.925** on the 80 test grids. This filter is used in the final `detect_objects` function.

## Notes

- The bounding boxes were generated automatically, not drawn by hand. A manual spot check estimates that roughly 3–5% of the final boxes are inaccurate, so the scores measure agreement with these generated boxes.
- The grids were generated again in a later Colab session, so the Task 3 test grids differ from the Task 2 test grids (1,316 vs 1,166 objects). Both sets contain only test-split photos, and the scores stay close.
