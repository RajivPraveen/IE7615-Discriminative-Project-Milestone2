# IE7615 Discriminative Project – Milestone 2: Multi-Object Detection with YOLOv8

Object detection on multi-object images built from the single-object photos of the course dataset (IE7615 Deep Learning for AI, Fall 2026). We combine single-object photos into grid images, custom-train **YOLOv8s** on them, and use the trained model to report the **Object ID and location** of every object in a new multi-object image.

The work covers **all 73 objects** in the shared sheet (38 from Section 01 and 35 from Section 03) and their **6,941 photos** at 224×224 from the Milestone 1 dataset.

## Repository contents

| Path | Description |
| --- | --- |
| `notebooks/Milestone_2_73_classes.ipynb` | The full pipeline: photo selection, automatic bounding boxes with YOLO-World and Grounding DINO, box fusion with a 20% per-object drop limit, label spot checks, generation of the multi-object grid dataset with YOLO labels, YOLOv8s training (with a resume cell for Colab disconnects), test evaluation, the one-detection-per-cell filter and the `detect_objects` function |
| `requirements.txt` | Python packages used |

## Dataset

The photos come from the course's Final Merged Dataset and are **not included** in this repository. The notebook reads `dataset_224.zip` and `metadata.csv`, which are produced by the Milestone 1 preprocessing notebook ([Milestone 1 repository](https://github.com/RajivPraveen/IE7615-Discriminative-Project-Milestone1)).

- The Milestone 1 train/validation/test split is reused (4,832 / 1,028 / 1,081 photos), so a source photo can never appear in more than one split.
- Photo `OBJ054_017` is excluded because it does not show the object.
- The dataset has object IDs but no bounding boxes. Boxes were generated by two open-vocabulary detectors (YOLO-World `yolov8l-worldv2` and Grounding DINO `grounding-dino-base`) and fused. The labelling was done in two batches with the same detectors: the Section 01 boxes are read from `labels.csv`, and the notebook labels the Section 03 objects. 6,006 of the 6,941 photos were kept (84% with two agreeing boxes), within the rule of dropping at most 20% of any object's photos.
- Grid images are built from 2×2 up to 5×5 photos (448×448 to 1120×1120 pixels), with a random horizontal flip and brightness change for each photo: **400 train, 80 validation and 80 test grids**, containing 8,689 labelled objects.

## How to run

The notebook was written for **Google Colab with a GPU runtime** (Runtime → Change runtime type → T4 GPU).

1. Run the Milestone 1 preprocessing notebook first, or copy its `dataset_224.zip` and `metadata.csv` into a Drive folder.
2. Put `labels.csv` (the Section 01 boxes) in the `M2_DIR` folder.
3. Open `notebooks/Milestone_2_73_classes.ipynb` in Colab and set the paths in Step 1:
   - `M1_DIR`: the folder with the Milestone 1 output (default `/content/drive/MyDrive/IE7615_pytorch`)
   - `M2_DIR`: where this milestone's labels, logs and checkpoints are saved (default `/content/drive/MyDrive/IE7615_detection`)
4. Run the notebook top to bottom. It writes `raw_detections_73new.json`, `labels_73.csv` and `grid_log_73.csv` to `M2_DIR`, the grid images with their YOLO labels and `data73.yaml` to `/content/grids73`, trains YOLOv8s to `M2_DIR/runs/yolov8s_73cls_seed42` and copies the best checkpoint to `M2_DIR/best_detector_73.pt`. If Colab disconnects during training, rebuild the grids (Steps 1 to 6) and run the resume cell.

Using the detector on any grid image (Step 10):

```python
found = detect_objects("path/to/grid.jpg", show=True)
# [{'object_id': 'OBJ001', 'name': 'Basketball', 'confidence': ..., 'box': [x1, y1, x2, y2], 'row': 0, 'col': 0}, ...]
```

To install the dependencies locally:

```bash
pip install -r requirements.txt
```

## Model and training

| Setting | Value |
| --- | --- |
| Model | YOLOv8s, COCO-pretrained, detection head replaced for 73 classes (11.16M parameters) |
| Image size | 1120 (the size of the largest grid) |
| Epochs / batch | 80 / 8 |
| Optimizer | AdamW (lr 0.00013, chosen automatically by Ultralytics), mixed precision |
| Augmentation | Mosaic off (the grids are already multi-object images); Ultralytics defaults for HSV, flip, translate and scale |
| Seed | 42 |
| Hardware | Tesla T4, 0.44 hours |

## Results

| Evaluation | Objects | Precision | Recall | mAP@0.5 | mAP@0.5:0.95 |
| --- | --- | --- | --- | --- | --- |
| Validation grids (best epoch 77) | 1,250 | 0.906 | 0.879 | 0.913 | 0.843 |
| **Test grids** | **1,194** | **0.919** | **0.891** | **0.924** | **0.866** |

- 47 of the 73 objects reach AP@0.5 ≥ 0.95. The weakest are the Neck Pillow (OBJ068, 0.334), the Mobile phone (OBJ013, 0.457) and the Headphones (OBJ062, 0.580).
- Section 01 and Section 03 objects are detected equally well (mean AP@0.5 0.924 and 0.925).
- Keeping only the most confident detection in each grid cell raises precision from 0.934 to **0.960** and F1 from 0.912 to **0.921** on the 80 test grids. This filter is the default in `detect_objects`.

## Notes

- The bounding boxes were generated automatically, not drawn by hand. A manual spot check estimates that roughly 3–5% of the final boxes are inaccurate, so the scores measure agreement with these generated boxes.
- Photos were often taken in bursts, so some test photos have a near-identical photo in the training set. Absolute test scores are therefore optimistic.
