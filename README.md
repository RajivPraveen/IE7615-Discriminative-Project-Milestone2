# IE7615 Discriminative Project – Milestone 2: Multi-Object Detection with YOLOv8

Object detection on multi-object images built from the single-object photos of the course dataset (IE7615 Deep Learning for AI, Fall 2026). We combine single-object photos into grid images, custom-train **YOLOv8s** on them, and use the trained model to report the **Object ID and location** of every object in a new multi-object image.

The work was done in two runs:

- **Model 1 (38 objects):** the first run covered the **38 Section 01 objects** (3,605 photos).
- **Model 2 (73 objects, final):** at the TA's request the pipeline was rerun over **all 73 objects** in the shared sheet (6,941 photos), adding the 35 Section 03 objects.

## Repository contents

| Path | Description |
| --- | --- |
| `notebooks/Milestone_2.ipynb` | Model 1, the full pipeline on the 38 Section 01 objects. **Task 1**: automatic bounding boxes with YOLO-World and Grounding DINO, box fusion with a 20% per-object drop limit, visual checks, and generation of the multi-object grid dataset with YOLO labels. **Task 2**: YOLOv8s training (with a resume cell for Colab disconnects) and test evaluation. **Task 3**: per-object evaluation, example detections, a post-processing comparison and the final `detect_objects` function |
| `notebooks/Milestone_2_73_classes.ipynb` | Model 2, the rerun over all 73 objects. It reuses the Section 01 labels, labels the 35 Section 03 objects with the same two detectors, rebuilds the grids over all 73 objects (seed 73), trains a new 73-class YOLOv8s, evaluates it on the test grids and rescores the one-detection-per-cell filter |
| `requirements.txt` | Python packages used |

## Dataset

The photos come from the course's Final Merged Dataset and are **not included** in this repository. The notebooks read `dataset_224.zip` and `metadata.csv`, which are produced by the Milestone 1 preprocessing notebook ([Milestone 1 repository](https://github.com/RajivPraveen/IE7615-Discriminative-Project-Milestone1)).

- The Milestone 1 train/validation/test split is reused (4,832 / 1,028 / 1,081 photos for all 73 objects), so a source photo can never appear in more than one split.
- Photo `OBJ054_017` is excluded because it does not show the object.
- The dataset has object IDs but no bounding boxes. Boxes were generated by two open-vocabulary detectors (YOLO-World `yolov8l-worldv2` and Grounding DINO `grounding-dino-base`) and fused. 6,006 of the 6,941 photos were kept (3,048 Section 01 and 2,958 Section 03), within the rule of dropping at most 20% of any object's photos.
- Grid images are built from 2×2 up to 5×5 photos (448×448 to 1120×1120 pixels), with a random horizontal flip and brightness change for each photo: **400 train, 80 validation and 80 test grids** per run.

## How to run

The notebooks were written for **Google Colab with a GPU runtime** (Runtime → Change runtime type → T4 GPU).

1. Run the Milestone 1 preprocessing notebook first, or copy its `dataset_224.zip` and `metadata.csv` into a Drive folder.
2. Open `notebooks/Milestone_2.ipynb` in Colab and set the paths in Task 1, Step 1:
   - `M1_DIR`: the folder with the Milestone 1 output (default `/content/drive/MyDrive/IE7615_pytorch`)
   - `M2_DIR`: where this milestone's labels, logs and checkpoints are saved (default `/content/drive/MyDrive/IE7615_detection`)
3. Run **Task 1** (Steps 1–9). This writes `labels.csv`, `dropped_photos.csv`, `per_object_summary.csv` and `grid_log_main.csv` to `M2_DIR`, and the grid images with their YOLO labels and `data.yaml` to `/content/grids`.
4. Run **Task 2**. Step 2 trains YOLOv8s and saves it to `M2_DIR/runs/yolov8s_main_seed42`. If Colab disconnects, regenerate the grids (Task 1, Steps 1 and 8) and run the resume cell (Step 3). Step 4 evaluates `best.pt` on the test grids.
5. Run **Task 3** for the per-object results, example detections, the post-processing comparison and the final detection function. The results are saved to `M2_DIR/evaluation`.
6. For the final 73-object model, open `notebooks/Milestone_2_73_classes.ipynb` with the same `M1_DIR` and `M2_DIR` and run it top to bottom. It needs the `labels.csv` from step 3, writes `labels_73.csv` and `grid_log_73.csv`, trains `M2_DIR/runs/yolov8s_73cls_seed42` and copies the best checkpoint to `M2_DIR/best_detector_73.pt`.

Using the detector on any grid image (`detect_objects` from Task 3 works with either checkpoint loaded as `model`):

```python
found = detect_objects("path/to/grid.jpg", show=True)
# [{'object_id': 'OBJ064', 'name': 'RGB Projector', 'confidence': 0.788,
#   'box': [78.5, 79.1, 137.5, 119.3], 'row': 0, 'col': 0}, ...]
```

To install the dependencies locally:

```bash
pip install -r requirements.txt
```

## Model and training

Both models use the same recipe:

| Setting | Value |
| --- | --- |
| Model | YOLOv8s, COCO-pretrained, detection head replaced for 38 or 73 classes (11.15M / 11.16M parameters) |
| Image size | 1120 (the size of the largest grid) |
| Epochs / batch | 80 / 8 |
| Optimizer | AdamW, mixed precision; lr chosen automatically by Ultralytics (0.000238 for 38 classes, 0.00013 for 73) |
| Augmentation | Mosaic off (the grids are already multi-object images); Ultralytics defaults for HSV, flip, translate and scale |
| Seed | 42 |
| Hardware | Tesla T4; 0.52 hours (Model 1), 0.44 hours (Model 2) |

## Results

| Evaluation | Objects | Precision | Recall | mAP@0.5 | mAP@0.5:0.95 |
| --- | --- | --- | --- | --- | --- |
| Model 1, validation grids (best epoch 57) | 1,237 | 0.950 | 0.926 | 0.955 | 0.902 |
| Model 1, test grids (Task 2) | 1,166 | 0.922 | 0.917 | 0.928 | 0.880 |
| Model 1, regenerated test grids (Task 3) | 1,316 | 0.925 | 0.896 | 0.922 | 0.871 |
| Model 2, validation grids (best epoch 77) | 1,250 | 0.906 | 0.879 | 0.913 | 0.843 |
| **Model 2, test grids (final)** | **1,194** | **0.919** | **0.891** | **0.924** | **0.866** |

- **Model 2** detects all 73 objects at the same test mAP@0.5 level as Model 1 on its 38 objects. 47 of the 73 objects reach AP@0.5 ≥ 0.95. The weakest are the Neck Pillow (OBJ068, 0.334), the Mobile phone (OBJ013, 0.457) and the Headphones (OBJ062, 0.580).
- The Section 01 objects average AP@0.5 0.924 in Model 2, against 0.922 in Model 1, so adding the 35 Section 03 objects did not make them worse on average.
- Keeping only the most confident detection in each grid cell raises precision from 0.934 to **0.960** and F1 from 0.912 to **0.921** for Model 2 (0.921 to 0.947 and 0.916 to 0.925 for Model 1). This filter is used in the final `detect_objects` function.

## Notes

- The bounding boxes were generated automatically, not drawn by hand. A manual spot check estimates that roughly 3–5% of the final boxes are inaccurate, so the scores measure agreement with these generated boxes.
- Model 1's grids were generated again in a later Colab session, so its Task 3 test grids differ from its Task 2 test grids (1,316 vs 1,166 objects). Both sets contain only test-split photos, and the scores stay close.
- Model 2 is a new model trained from COCO weights, not a continuation of Model 1, because a 38-class checkpoint cannot be resumed with a 73-class head.
